vv-switch

LLM API 协议转换代理 —— 让 Claude Code 和 OpenAI Codex 连接国内主流LLM 提供商

立即开始

核心特性

🔄

双向协议转换

支持 Responses API ↔ Chat Completions、Anthropic Messages ↔ Chat Completions 的双向转换，完整保留工具调用和推理内容。

🏢

多供应商支持

内置对 DeepSeek、DashScope（阿里百炼）、智谱、Ollama 等国内外 LLM 提供商的支持，可灵活配置和切换。

📊

可视化日志

JSONL 格式日志保存在 .vv-switch-logs/ 目录，内置 HTML 日志查看器，支持会话列表、搜索过滤和自动刷新。

⚙️

配置管理

友好的 Web UI 管理供应商配置，支持 Claude Code 和 OpenAI Codex 的一键配置应用，停止服务时自动还原。

🔒

安全备份

自动备份原始配置文件到用户顶层目录，Ctrl+C 停止服务时从磁盘备份或内存副本完整恢复原有配置。

🚀

流式支持

全链路 SSE 流式支持，正确的增量文本 delta、工具调用参数 delta、finish reason 和 usage tokens 处理。

核心功能支持

  • ✅ 多轮工具调用（tool calling）
  • ✅ SSE 流式响应与增量 delta
  • ✅ 推理内容（reasoning_content）
  • ✅ temperature / max_tokens / top_p 参数映射
  • ✅ tool_choice 策略转换

配置注入机制

Claude Code：修改 ~/.claude/settings.json，设置 ANTHROPIC_BASE_URL 等环境变量

OpenAI Codex：修改 ~/.codex/config.toml，添加 vv-switch 模型提供商

自动还原：Ctrl+C 停止时从备份恢复原始配置

协议转换细节

vv-switch 自动处理不同 API 协议之间的字段映射，让你可以无缝切换各大 AI 提供商

Responses API → Chat Completions
1
对话历史转换

instructions → system 消息

input[] → messages[] 数组

2
工具调用映射

function_call → assistant.tool_calls[]

function_call_output → tool 角色消息

3
流式响应处理

工具参数增量拼接 arguments += delta

检测到 finish_reason: "tool_calls" 时关闭消息

4
其他参数映射

max_output_tokens → max_tokens

reasoning.effort → reasoning_effort

Anthropic Messages → Chat Completions
1
系统提示词处理

system 字段 → system 消息

支持文本和 content block 数组格式

2
消息内容转换

user.content[] → content 字符串

assistant.tool_use[] → tool_calls[]

3
工具结果处理

上游不支持 tool role 时降级为 user 消息

tool_result → 格式化为用户可读文本

4
参数传递

max_tokens、temperature、top_k

tool_choice 策略转换（any/auto/tool）

Anthropic Messages → Anthropic Messages
1
最小化处理

直接透传请求，仅替换 model 字段

修正 message ID 保持一致性

2
URL 智能适配

/v1 → /v1/messages

自动识别不同上游端点格式

3
SSE 事件透传

所有事件原样转发，零延迟传递

修正 message_start 的 id/model

4
适用场景

DashScope /apps/anthropic

智谱等原生兼容端点

URL 智能处理

buildChatUrl("https://api.deepseek.com/v1") → "https://api.deepseek.com/chat/completions"
buildMessagesUrl("https://dashscope.aliyuncs.com/apps/anthropic") → "https://dashscope.aliyuncs.com/apps/anthropic/v1/messages"

快速安装

# 带日志启动服务（默认端口 4321）
# 日志在当前目录.vv-switch-logs,
# 浏览器打开里面的html文件即可，每次请求后，刷新下网页即可查看最新数据
npx vv-switch --logs

# 不带日志启动 (推荐，减少日志对磁盘占用)
npx vv-switch

# 打开配置页面
# 浏览器访问 http://localhost:4321

访问 http://localhost:4321 打开配置管理界面
